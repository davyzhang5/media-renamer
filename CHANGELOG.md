# Changelog

## 0.5.0

- Add a Windows x64 NSIS installer to the automated release workflow.
- Bundle FFmpeg and FFprobe for Windows.
- Add Windows local-model runtime downloads and automatic installation.
- Fix cross-platform path handling after batch renames and undo.
- Keep Apple Silicon and Intel macOS builds in the same release.

- Add one-click local vision model download and automatic setup.

- Detect existing local models automatically.
- Improve image and video analysis performance.
- Add persistent analysis caching and background model preloading.
- Add configurable draggable filename fields.
- Keep video duration fields active only for video files.
- Add the unified black-and-white M application icon.
- Add GitHub Actions builds for macOS Apple Silicon and Intel.
